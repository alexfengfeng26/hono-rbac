## 十、钱包模块

### 钱包主页（/pages/wallet/index）
**字段：**
- 金币余额（76400.00）
- 余额（¥0.00）
- 操作：**充值**、**兑换**（金币↔余额）、**提现**

**规则说明（系统文案）：**
- 金币可通过充值或收到礼物获得
- 100金币 = 1元，可兑换成余额
- 金币用于送礼打赏，余额可用于提现
- 最低提现 ¥40，仅支持固定金额档位
- 收款方式为银行卡转账，不支持即时到账
- 提交后需人工审核，到账时间 1-3 个工作日
- 余额不足最低门槛时暂无法提现

### 金币充值（/pages/wallet/recharge）
**字段：**
- 当前金币（76400）
- **充值档位：** 100金币 ¥1.00 / 500金币 ¥5.00 / 1000金币 ¥10.00 / 5000金币 ¥50.00 / 10000金币 ¥100.00 / 自定义（输入金币数量）
- 兑换比例说明：100金币 = 1元
- 充值用途：充值后可用于送礼、订单等消费（支持小数）
- 最小充值 1金币（¥0.01）
- 立即充值按钮

### 提现申请（/pages/withdraw-apply/index）
**字段：**
- 可提现余额（¥301.01）
- 收入明细（入口）
- 选择提现金额：**固定档位** ¥40 / ¥80 / ¥120 / ¥160 / ¥200 / ¥400 / ¥800 / ¥1000（不支持自定义）
- **收款银行卡信息：**
  - 持卡人姓名（必填）
  - 所属银行（必选，如"中国工商银行"，带选择器）
  - 开户支行（必填）
  - 银行卡号（必填）
- 提交审核申请按钮

**提现规则（系统文案）：**
- 非即时到账，提交后需人工审核，审核通过后打款至银行卡
- 可提现额度：当前余额 xx，单次最高 ¥1000.00
- 最低门槛：余额满 ¥40.00 方可申请
- 每日次数：每日最多申请 1 次；有待审核申请时不可重复提交
- 申请时间：全天 24 小时可提交，工作日审核更快
- 审核时间：人工审核，通常 1 个工作日内完成
- 到账时间：审核通过后 1-3 个工作日内到账
- 提现流程：提交申请→金额冻结扣除→人工审核→打款/退回余额

## 附：核心业务规则汇总

1. **货币体系**：金币（消费/送礼）↔ 余额（可提现），100 金币 = 1 元；金币可充值获得或收到礼物获得
2. **护航赔付**：护航单未达标，平台先行赔付
3. **提现规则**：最低 ¥40、固定档位、每日 1 次、人工审核 1-3 个工作日到账
4. **接单体系**：平台官方/工会发布派单 → 陪玩在接单大厅抢单 → 完成结算拿分成（工会抽取比例）
5. **技能认证**：考核 / 上传段位截图两种方式，不同等级对应不同定价权益
6. **贵族体系**：6 级爵位（星耀→星帝），月/季/年卡，8 折优惠，专属特权展示
7. **分销体系**：生成链接推广，按订单结算佣金；邀请好友注册得"我的邀请"记录
8. **工会体系**：工会管理成员、设置抽成比例、发布工会专属派单
