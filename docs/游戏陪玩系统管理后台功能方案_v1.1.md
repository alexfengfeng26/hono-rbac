## 一、系统概览

| 项 | 内容 |
| --- | --- |
| 产品名 | 游戏陪玩系统（ANGAME v5.1.8 框架） |
| 形态 | Angular 桌面壳（`_apps_pc.html`）+ 内嵌 Vue Element 后台（`/admin/`） |
| 角色定位 | 陪玩平台运营管理后台（B 端 SaaS） |
| 主营场景 | 游戏陪玩下单、护航代练、试音/音乐互动房间、虚拟礼物、爵位订阅、社区动态、分销推广、工会入驻 |
| 用户分两类 | 普通用户（老板/下单方）、陪玩用户（接单方/主播），通过技能认证 + 实名认证区分 |
| 货币体系 | 现金（¥） + 金币（1 元 = 100 金币，可配置）双轨；金币用于礼物、签到等站内消耗 |

### 核心价值主张（首页文案）
- 「专业 · 高效 · 安全」游戏陪玩系统管理平台
- 一站式管理陪玩服务、用户、订单与数据
- 助力平台高效运营与业务增长

## 二、角色与权限

| 角色 | 来源 | 说明 |
| --- | --- | --- |
| 超管 / 平台管理员 | `admin` 内置 | 拥有所有菜单权限 |
| 子账号 | 「子账号管理」创建 | 可绑定角色，控制细粒度权限 |
| 角色 | 「角色管理」维护 | 已内置「超管」「试音房主持」两种 |
| 试音房权限 | 「试音房权限」Tab | 按子账号授权可主持的平台/公会/用户自建房间 |

权限模型：菜单权限 + 角色 + 子账号三层。系统设置中可控制试音房、音乐厅、签到、客服等模块的总开关。

## 四、模块详细功能清单

### 1. 仪表盘
- 4 个核心卡片：总用户数 / 总订单数 / 总订单金额 / 状态分布（已完成·进行中·已取消·待分账）
- 4 个统计图：订单类型占比饼图 / 订单趋势对比柱状（7/30/90 天） / 陪玩单状态分布 / 护航单状态分布
- 2 个排行表：陪玩单·服务统计（订单数/金额/占比） / 护航单·套餐统计 / 陪玩接单排行（昵称/单量/金额/完成率）
- 所有图表支持「刷新」按钮单独刷新

### 2. 用户管理 (`/admin/user-management`)
- 搜索：用户名 / 昵称 / 手机号
- 批量操作：批量启用 / 批量禁用 / 批量删除 / 导出
- 单行操作：查看 / 编辑 / 删除 / 更多（金币记录 / 余额记录 / 关闭）
- 字段：ID / 头像 / 用户名 / 昵称 / 手机号 / 邮箱 / 用户类型（普通·陪玩）/ 状态（正常·封禁）/ 爵位 / 称号 / 金币 / 余额（元）/ 注册时间
- 底部统计：用户总数 · 普通用户 N · 陪玩用户 N
- 分页：20 条/页（可调）

### 3. 陪玩服务
#### 3.1 服务列表 (`/admin/accompany-service`)
- 搜索：服务标题 / 描述或标签
- 批量：批量推荐 / 批量取消推荐 / 批量开分销 / 批量关分销 / 批量删除
- 行操作：查看 / 删除 / 更多（编辑 / 上/下架）
- 字段：ID / 游戏 / 服务标题 / 发布者 / 价格（元/小时）/ 评分 / 接单 / 浏览 / 标签 / 状态 / 推荐 / 分销 / 创建时间 / 评价数
- 底部统计：服务总数 / 正常 / 推荐 / 可分销
- 计费维度：按小时 / 按局 / 两种都支持
- 支持「上分带飞 / 国服王者 / 代练 / 枪法准」等多维度标签

#### 3.2 服务标签配置 (`/admin/service-tag-management`)
- 添加标签 / 批量启用 / 批量下架
- 字段：标签名称 / 排序 / 状态 / 编辑
- 标签库示例：技术指导 / 娱乐陪玩 / 上分带飞 / 语音聊天 / 高端局 / 低端局 / 双排 / 五排 / 带飞 / 高级 / 甜美音 / SS 级 / 代练 / 枪法准 …（34 条）
- 排序可调，支持权重曝光

### 4. 陪玩订单 (`/admin/order-management`)
- 搜索 + 导出全部
- 字段：ID / 订单号 / 客户信息 / 陪玩信息 / 服务标题 / 游戏 / 订单金额 / 订单状态（待接单·待支付·已支付·已完成·已取消·已退款）/ 支付状态 / 开始时间 / 创建时间
- 行操作：详情（弹窗显示服务流程 / 陪玩分配 / 评价 / 投诉记录）
- 底部统计：订单总数 · 待支付 N · 已完成 N

### 5. 护航单管理（代练 / 上分）

#### 5.1 套餐管理 (`/admin/escort-product-list`)
- 新增套餐 / 批量上架 / 批量下架 / 批量删除
- 字段：ID / 封面图 / 套餐标题 / 游戏名称 / 定价 / 状态（上下架）/ 虚拟销量 / 真实销量 / 排序 / 创建时间
- 行操作：编辑 / 删除
- 套餐示例：LOL·黄金升铂金 ¥98 / 王者·黄金升铂金护航 ¥88 / 三角洲·绝密 500W 保底 ¥198 / 和平·地铁逃生护航 ¥118 / 永劫·三排吃鸡护航 ¥108

#### 5.2 护航单列表 (`/admin/escort-order-list`)
- 搜索 + 导出全部 + 批量删除
- 字段：ID / 护航单号 / 用户昵称 / 游戏名称 / 服务名称 / 总金额 / 补单次数 / 状态（待支付·待配单·进行中·待分账·已完成）/ 创建时间
- 核心行操作：
  - **配单** — 手动分配陪玩/打手
  - **分账** — 护航单完成后平台 + 陪玩分账（这是关键流程）
  - 查看详情 / 删除

#### 5.3 补单申请审核 (`/admin/escort-supplement-application-list`)
- 字段：申请 ID / 用户 ID / 护航单号 / 申请用户 / 游戏名称 / 补单次序 / 描述摘要 / 状态（待审核·已通过·已拒绝）/ 申请时间
- 批量通过 / 批量删除
- 业务：护航失败后用户申请补单，管理员审核

### 6. 派单管理

#### 6.1 派单订单 (`/admin/dispatch-order-list`)
- 发布派单 / 批量取消 / 批量删除
- 字段：ID / 派单号 / 归属（平台·工会）/ 工会 / 标题 / 游戏 / 接单方式（抢单·指派）/ 陪玩分成 / 本单金额 / 接单人 / 状态 / 创建时间
- 行操作：详情 / 取消 / 删除
- 业务：平台或工会可发布派单任务，陪玩抢单完成
- 底部统计可见工会专属派单（例：星耀电竞俱乐部）

### 7. 游戏管理

#### 7.1 游戏管理 (`/admin/game-management`)
- 新增游戏 / 批量启用 / 批量禁用 / 批量删除
- 左侧分类树：全部分类 / 测试分类 / 怀旧游戏 / 独立游戏 / VR 游戏 / 主机 / 手游 / 端游
- 字段：ID / 图标 / 游戏名称 / 描述 / 等级类型（段位制·其他）/ 认证陪玩（人数）/ 热门 / 状态 / 分佣比例 / 排序
- 行操作：编辑 / 等级（跳到游戏等级配置）/ 删除
- 游戏示例：王者荣耀/lolm、金铲铲、和平精英、英雄联盟、Delta/无畏契约、PUBG/永劫无界

#### 7.2 游戏等级 (`/admin/game-level-management`)
- 添加等级 / 批量启用 / 批量禁用 / 批量删除
- 字段：ID / 游戏 / 等级名称 / 等级描述 / 认证方式（上传资质·考核）/ 资质说明 / 价格区间（小时·局）/ 排序 / 状态
- 示例等级：
  - 王者以下娱乐（按小时 ¥10-60 / 按局 ¥10-50）
  - 王者以上娱乐（按小时 ¥30-80 / 按局 ¥15-50）
  - 王者以上乱杀（按小时 ¥50-150 / 按局 ¥0.01-80）
- 行操作：编辑 / 删除

### 8. 页面装修 (`/admin/diy-page`)
- DIY 页面模板管理
- 字段：ID / 模板名称 / 页面标识（`tongyong`）/ 状态 / 创建时间
- 行操作：编辑 / 删除
- 业务：管理员可配置客户端页面布局/组件（通用页面）

### 9. 认证管理

#### 9.1 实名认证 (`/admin/real-name-management`)

- 字段：ID / 用户 ID / 用户信息 / 真实姓名 / 身份证号 / 联系电话 / 身份证照片（正面·反面）/ 状态 / 拒绝原因 / 提交时间

## 五、核心业务流程

### 流程 1：陪玩下单闭环
```
客户浏览服务 → 下单 → 订单状态: 待接单/待支付
   ↓ 支付
待接单 → 陪玩接单 → 进行中 → 已完成 → 自动结算 → 佣金入账
   ↓ 超时未接单
自动取消 → 退款 → 流水记入
```

### 流程 2：护航单闭环（最复杂）
```
客户选套餐下单 → 待支付 → 已支付(待配单)
   ↓ 平台手动「配单」分配打手
进行中 → 申请补单(描述未达标) → 平台审核补单 → 通过则继续
   ↓ 完成
待分账 → 平台「分账」 → 分账给打手 → 已完成
```

### 流程 3：分销推广闭环
```
陪玩申请分销员 → 平台审核(查看身份证/手机号)
   ↓ 通过
获得分销员唯一码 + 游戏设置(可分销游戏)
   ↓ 分享服务链接
下单时填分销码 → 自动记录分销记录 → 订单完成 → 结算佣金
```

### 流程 4：试音流程（高级功能）
```
平台/工会/用户创建房间 → 设置类型(vip/normal/guild) + 标签 + 配置(轮/人/分/人/波)
   ↓ 老板进入
陪玩依次试麦(试音时长 1-5 分钟) → 老板挑选 → 私聊或下单
   ↓ 全程
礼物可送 → 平台/工会抽成（系统设置中配置）
```

### 流程 5：爵位订阅闭环
```
用户选爵位等级 + 时长(月/季/年) → 下单支付 → 生效(权益开启)
   ↓ 快到期
提醒即将过期 → 用户续费 / 自动失效 → 过期数据批量处理
```

## 九、可扩展/可改造点（产品视角建议）

1. **音乐厅**与**试音厅**架构完全对称，可抽象成「互动房间」统一组件；目前两边分别维护一份类型/标签配置
2. **订单类型**（陪玩单 / 护航单 / 派单单）状态机可统一抽象，配套配置化驱动
3. **分销 + 邀请**两条线分开，但都基于「订单 + 抽成」，可合并为「推广返佣」单一引擎
4. **陪玩认证 + 实名认证**两条审批流，目前相互独立，但流程相似，可考虑统一工单中心
5. **爵位 / 称号** 都是身份权益体系，可合并为「荣誉与订阅」模块
6. **金币体系**贯穿礼物、签到、分销、爵位购买，财务流水记账完整，可作为支付中台抽离
